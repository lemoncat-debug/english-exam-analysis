独立目录由通用版克隆，保留完整 Git 历史、原站 ID、2010 旧精读入口与存储键。旧项目和源 PDF、照片未修改。当前没有发布新版本，待 Luna Max 翻译生成和最终验收后发布。

## 无 API 的架构

用户已明确只有 Codex/ChatGPT 额度，没有 OpenAI API 密钥。网站不自动联网调用模型，不能将 Codex 额度当作网站 API。当前“问 AI”整理本题最小上下文，用户复制到 Codex，答复贴回本题保存。它不是自动流式对话，也不假称网站调用 Terra/Astra。自动视觉手写识别和自动错因分析尚不可用，照片答案必须人工核对。

静态站保留 Tesseract OCR 与 ExamMatch 匹配算法。flow.js/flow.css 提供连续原题、照片、文字和解析阅读、手机快捷栏、本地词句读取、错题与生词记录；local-tools.js 提供 PDF 本机导入、答案确认与 Codex 上下文交接。PDF.js、OCR 字库和题库均在本站，无第三方 CDN。

原题每年 14 页连续排列；没有上传照片的页显示空态。宽度不超过 1050px 使用单列来源切换。图片按视口及相邻区域加载，远处释放图像 DOM；尺寸元数据避免加载跳位。底部常驻单词/句子、当前题、问 AI、下一错题。透明 SVG 高亮、显式文字颜色和键盘焦点防止遮住原图。

## 判分、保存和隐私

只有用户填写并确认的答案才进入判分。2010 第 1—40 题沿用旧版已核验标准答案和来源；其他题没有可靠标准答案时显示“暂不能核验”。模型猜测不能成为标准答案。

旧 english-universal.records.v1 和 english-universal/photos 继续读取。新版逐题对话、生词状态、确认与掌握记录使用 english-flow.v1。损坏记录先保留 recovery 副本；不会因升级清空旧记录。

导入 PDF 只保存在本机 IndexedDB，限制 30 MB、100 页；保存原文件、哈希、页图、文本与下一页位置。重复文件不重复处理，取消后重新选择同一文件可以续传。删除进入可恢复回收区。文本 PDF 直接提取，扫描 PDF 目前通过英文 OCR 建检索索引；中文原书仍显示图像，不能假称已有完整中文摘录。

Service Worker 有界缓存已加载资源，离线可查看已缓存内容，未缓存页仍需联网。浏览器清理或空间不足可能丢失本机数据；不同设备不同步。JSON 导出不含照片和 PDF，原始文件应保留。当前仅用户主动把上下文复制进 Codex 才涉及 Codex 分析，网站不自动发送照片或题目到模型。
