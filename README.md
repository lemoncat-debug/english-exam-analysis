# 考研英语 · 连续精读（Luna 语境翻译开发阶段）

**当前升级状态、无 API 的使用方式、数据生成和测试见 [README_FLOW.md](README_FLOW.md)。本次尚未发布，正在按用户选择的 Luna Max 继续生成静态语境翻译；2010—2022 全年已完成。以下保留旧通用版说明供对照，不代表此次升级全部完成。**

基于用户提供的英语二资料库，上传作答照片后自动对应年份、原题页与原书解析。保留第二版于 `dist/2010/`；网站主页为新的通用流程。

## 使用

1. 上传照片或用手机相机拍摄，支持一次最多 10 张，每张 20 MB。
2. 系统按正文识别年份与页码，并校正文字方向。候选接近、字数不足时由用户核对。
3. 题目页会尝试选中照片中的题号，右侧展示对应原书解析；解析可翻页、放大。
4. 在照片或原题上点词查字典，切换句子定位原书中的译文和句法讲解。
5. 核对原始作答并写笔记。照片保存在 IndexedDB；记录保存在 localStorage，可以导出和恢复。

## 实现与限制

- 通过浏览器 Tesseract OCR、加权词组匹配与相邻候选差异判断照片所属页面，不依赖固定图片文件名。
- 资料库有 2021 年反向隐藏文字等问题，已通过页面 OCR 修复；题号、跨页写作结构已校正。
- 原题页匹配与解析页定位分开完成。用题号锚点和英文词组优先寻找讲解页，遇到跨页可翻页继续。
- 不自动把手写涂改识别为最终答案，不自动给新照片判分；用户确认作答后对照原书解析。
- 通用版的“句子”展示原书对应译文/讲解页面，不承诺所有年份都输出独立的逐句中文文本。2010 精读版保留已整理的直接整句翻译。
- 未收录的试题不能凭照片生成可靠解析；需要补充对应资料。
- 没有接入在线生成式 AI，也没有跨设备云同步。导出的 JSON 备份不含照片。
- 2010 精读版原有记录使用其原存储键，通用版使用独立记录，不覆盖旧记录。

## 开发

`dist/` 是静态网站，可以直接用 HTTP 服务运行。运行时不需要 Python 或 API 密钥。开发检查使用 Node.js，OCR 测试使用 package.json 中的 Tesseract.js。

资料处理顺序：`build-library.py` → `ocr-references.cjs` → `repair-exam-ocr.cjs` → `refine-library.py` → `compress-reference-assets.py` → `fit-hosting-assets.py`。Python 使用 pdfplumber、pypdfium2、Pillow。构建脚本中的源资料路径指向用户提供的本地目录。原始 PDF 不被修改。

`scripts/cache/` 存放 OCR 与测试中间文件，不发布、不进入 Git。实际照片集成测试依赖本机生成的测试图片与 OCR 缓存；普通 `npm run check` 可在源码检出后运行。
